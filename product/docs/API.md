# Функции и HTTP API

## Возможности интерфейса

| Функция | Что доступно |
|---|---|
| Фото и очередь | Одна фотография или несколько, прогресс, удаление материала, отмена ожидания и очистка сессии |
| Просмотр | Фото, маска, разделитель сравнения, выбор компоненты, прозрачность, масштаб и перемещение |
| Ручная проверка | Ручные области, комментарий и отдельное решение оператора |
| Отдельный исходник | Синхронное сравнение двух загруженных файлов, переключение, увеличение и карта различий |
| Короткое видео | До 60 секунд, до 12 кадров; находки на временной шкале и указание проверенных моментов. Проверяются выбранные кадры, не каждый кадр видео |
| Обращение | Несколько материалов одного случая, общий статус, нерешённые вопросы и единый отчёт |
| Сохранение | Полная проверка с фото, маской, ручными отметками и пояснениями; открытие, экспорт JSON/отчёта/маски |
| Пояснение | Платная подсказка OpenRouter/Together для выбранной области, успешные ответы кешируются |
| MCP | Статус, анализ, фото/маска/наложение и пояснение; [подключение](MCP.md) |

Обычный сценарий: фото → маска → осмотр области → при необходимости пояснение → отметки и решение → сохранение/отчёт. Изображение до редактирования не требуется; сравнение с отдельным исходником возможно, если пользователь его загрузит.

История находится в IndexedDB браузера, отдельно для каждого адреса/порта. Для переноса скачивайте проверку или обращение. Начатый серверный расчёт или платный запрос может завершиться после отмены в интерфейсе. Открытие обращения может заменить текущую сессию после подтверждения.

## Ручки

Примеры используют `http://127.0.0.1:8080`. Файлы передаются как `multipart/form-data`.

| Метод | Вход / ответ |
|---|---|
| `GET /` | Основной интерфейс |
| `GET /legacy` | Прежний интерфейс |
| `GET /health` | Готовность, устройство, SHA256 и настройки модели, доступность пояснений |
| `GET /metrics` | JSON: счётчики, ошибки, задержки и очередь |
| `POST /detect?mask=true` | Поле `file`; детекция и PNG-маска в base64. `mask=true` по умолчанию |
| `POST /detect/batch?mask=true` | От 1 до 20 полей `files`; ответ `{"items":[...]}`. `mask=false` по умолчанию; обработка последовательная, ошибка прерывает batch |
| `POST /explain` | Поля `file`, `mask`, `prediction_id`, `region_id`; подсказка выбранной области или кеш |
| `GET /docs`, `/redoc`, `/openapi.json` | Интерактивная документация и схема |

```bash
mkdir -p inputs results
curl --fail -F 'file=@inputs/photo.jpg' \
  'http://127.0.0.1:8080/detect?mask=true' -o results/detection.json
python3 - <<'PY'
import base64, json
from pathlib import Path
result = json.loads(Path('results/detection.json').read_text())
Path('results/mask.png').write_bytes(base64.b64decode(result['mask_png_base64']))
print(result['prediction_id'], result['n_regions'])
PY
```

Для пояснения используйте ID из ответа и номер существующей компоненты из `regions`:

```bash
curl --fail -F 'file=@inputs/photo.jpg' -F 'mask=@results/mask.png' \
  -F 'prediction_id=PREDICTION_ID' -F 'region_id=1' \
  http://127.0.0.1:8080/explain
```

Фото и маска должны быть **теми же байтами**, что использовались в детекции; повторно закодированная маска не пройдёт проверку хеша. API держит метаданные последних 20 проверок с маской в памяти. После вытеснения или перезапуска детекцию нужно повторить.

## Поля детекции

| Поле | Значение |
|---|---|
| `prediction_id`, `input_sha256`, `analysed_at` | ID проверки, хеш исходных байтов, время UTC |
| `width`, `height`, `mask_png_base64` | Геометрия с учётом ориентации; одноканальный PNG 0/255 исходного размера |
| `area_frac` | Доля изображения под маской, 0–1 |
| `regions` | До 32 компонент: `x,y,width,height`, площадь и вероятности; координаты от левого верхнего угла |
| `n_regions` | Полное число компонент; PNG содержит всю маску |
| `score` | Некалиброванный top-logit, не вероятность; может выходить за 0–1 |
| `manipulated` | Совместимый флаг `area_frac > 0.01`. При маленькой непустой маске может быть `false`; маска всё равно отображается |
| `model`, `inference_ms` | Конфигурация модели и время детектора; это не вся задержка HTTP |

`region_id` начинается с 1. Пустой маске локальное пояснение не запрашивается. При `cached=true` стоимость относится к первому запросу, а не новому списанию.

## Лимиты и ошибки

JPEG/PNG/WebP до 20 МиБ и 15 млн пикселей. Переносимый JSON проверки — до 300 МиБ; у обращения — до 250 МиБ бинарных данных.

`413` — лимит; `415` — формат; `422` — поля или область; `409` — несовпадение байтов или занятое пояснение; `410` — устаревшая проверка; `502/504` — провайдер/таймаут; `503` — выключенная функция, очередь или модель. `/explain` отклоняет посторонний browser Origin с `403`.

Видео, сравнение, история и обращения реализованы в браузере; отдельных серверных CRUD-ручек для них нет. API без авторизации рассчитан на закрытый доступ. Жёлтый цвет наложения искусственный; маска и VLM-подсказка не доказывают подделку и не устанавливают тип операции.

Для №121 `/health.model.threshold` — базовые 0.675; `/detect.model.threshold` — фактически выбранный порог изображения. `threshold_mode=lower_only_calibrated`, список допустимых значений находится в `candidate_thresholds`.
