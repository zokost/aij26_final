HTTP API

Адрес текущего сервиса:

  • GET /health — готовность и версия модели.
  • POST /detect — фото, маска и области.
  • POST /explain — отдельная подсказка для выбранной области.

Агент через MCP

Адаптер product.mcp_server работает поверх API и использует уже загруженную модель. Файлы читаются внутри разрешённой папки image-root.

Пример поручения агенту:

Проверь предоставленный файл inputs/photo.jpg через
aij-photo-review. Вызови analyze_image, затем get_analysis_views.
Опиши выделенную область и ограничения вывода.
Платное explain_region пока не вызывай.

explain_region отдельно отправляет фото и маску в OpenRouter/Together. MCP не управляет браузерными обращениями и видео.

ПАМЯТКА ОПЕРАТОРУ

От находки — к решению.

Три шага, чтобы интерпретировать результат аккуратно.

01

Найдите область

Маска указывает, на какой участок стоит обратить внимание. Даже маленькая область может содержать важную деталь.

02

Рассмотрите контекст

Увеличьте фрагмент, отключите маску и сравните его с соседними участками. Маска сама по себе не определяет тип операции.

03

Зафиксируйте вывод

Отделяйте наблюдение от решения. Сохраните комментарий и отчёт, чтобы передать материал на дальнейшую проверку.

Как работает этот прототип

Результат модели и учебная разметка имеют разные источники.

Пустая маска не удостоверяет подлинность. Демонстрационные области не являются результатом проверки модели. Сохранение проверки включает файл и результат; скачанный файл проверки можно открыть без нового анализа. Учебные примеры в истории сохраняют только решение.
