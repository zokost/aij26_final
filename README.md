# AIJ2026 — Цифровой детектив

Сегментация локальных ИИ-изменений на фотографиях. Основное решение финального
этапа — **KDALL**: одна модель SegFormer MiT-B2 с декодером шириной 320,
вход 640×640, веса эпохи 32, порог 0.75, FP32-инференс без TTA.
Результат посылки №113: public AIC **0.822791**; нагрузка — **93.097 GFLOPs**.

| Каталог | Содержимое | Инструкция |
|---|---|---|
| `stage2/` | Финал: дообучение трёх учителей, мягкие NB-маски, обучение и инференс KDALL | [Второй этап](stage2/README.md) |
| `stage1/` | Первый этап: обучение MiT-B2, усреднение весов, инференс и три фолда больших моделей | [Первый этап](stage1/README.md) |

`common.py` содержит общие лосс, нормализацию и настройку случайности.
Зависимости обоих этапов — в `requirements.txt`. Данные, подготовленные маски,
списки изображений и веса хранятся отдельно от кода. Перечень весов первого
этапа и их SHA256 — в [weights.json](weights.json).

Все команды запускаются из корня репозитория, Python 3.10+ и CUDA:

```bash
pip install -r requirements.txt
```

Для инференса готовой финальной модели поместите исходные веса KDALL эпохи 32
в `weights/KDALL_epoch32.pt`:

```bash
python -m stage2.infer --checkpoint weights/KDALL_epoch32.pt --root data/test_stage2 --csv data/test_stage2/test.csv --out work/submission_stage2
```

Результат — `work/submission_stage2/submission.zip`: CSV и отдельные одноканальные
PNG-маски со значениями 0/255 в исходном размере изображений. Подготовка данных
и команды обучения описаны в инструкциях соответствующих этапов.
