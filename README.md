# AIJ2026 — Цифровой детектив

Сегментация локальных ИИ-изменений на фотографиях. Лучшее решение —
**NC17 + адаптивный порог**, посылка **№121**, public AIC **0.831234**.
Модель возвращает бинарную маску в исходном размере изображения.

## Как устроено решение

На инференсе работает **одна SegFormer MiT-B2 с декодером шириной 320**.
Изображение растягивается до 640×640 без полей, нормализуется по ImageNet;
логиты восстанавливаются в исходный размер, затем применяется sigmoid.
Используются веса **epoch=32**, FP32, без ансамбля, SWA и TTA.

Обучение объединяет официальные stage2-маски и мягкие цели Nano-Banana (NB).
Три больших ConvNeXt-L / UPerNet дообучаются по фолдам и дают цели на NB;
ещё три — цели на stage2. Каждый пример размечает учитель, из дообучения
которого исключён соответствующий фолд. Учителя нужны только при обучении.

| Компонент | Рецепт NC17 |
|---|---|
| Инициализация | Энкодер stage1, среднее эпох 156–160; свежий декодер, seed 42 |
| Данные на эпоху | 19 837 stage2 + 1 999 мягких NB + 1 999 парных чистых исходников |
| Пул NB | 9 693 пары; состав 1 999 пар меняется по подготовленным спискам эпох |
| Оптимизация | BF16, AdamW, batch 18, LR 1e-4; LR энкодера 1e-5; warmup 5%, cosine на 40 эпох |
| Основной лосс | 0.5 BCE + 0.5 per-image Tversky, β=0.7; штраф площади для чистых кадров |
| Дистилляция stage2 | Дополнительный BCE ×0.6 по вероятностям учителя; официальная GT сохраняется |
| Аугментации | HFlip 0.5, VFlip 0.2, JPEG 90–100 с вероятностью 0.2 |

Порог адаптирует **ExtraTreesRegressor**: 32 дерева, depth 5, leaf 64.
Он получает 276 признаков карты вероятностей, изображения и того же forward
энкодера и предсказывает выигрыш Dice относительно базового порога **0.675**.
Допустимые пороги: **0.50 / 0.60 / 0.65 / 0.675**. Если базовая маска занимает
менее 1% кадра или положительный выигрыш не предсказан, порог остаётся базовым.
Поэтому калибровка не добавляет image-level тревог относительно своей базы.
Scaler, PCA и деревья обучаются на выделенной части NB/stage2.

## Готовые веса и инференс

Python 3.10+, CUDA. Все команды — из корня репозитория:

```bash
pip install -r requirements.txt
```

Веса `model.pt`, `policy.pkl`, `encoder_transform.pkl` —
[в отдельном каталоге](https://github.com/zokost/aij_2026/tree/main/weights_final/121_NC17_e32).
Положите их в `weights/121/`. SHA256 — в [weights.json](weights.json).

```bash
python -m stage2.infer --checkpoint weights/121/model.pt --calibration weights/121 --root data/test_stage2 --csv data/test_stage2/test.csv --out work/submission
```

Результат — `work/submission/submission.zip`: CSV и отдельные PNG-маски 0/255
в исходном размере. По умолчанию FP32 batch 4 воспроизводит маски №121.
Повторное обучение может дать немного другие веса; точную посылку воспроизводят
сданные модель и калибратор без обучения.

## Полное обучение второго этапа

Нужны изображения и подготовленные разностные NB-маски в `data/`,
CSV из `manifests_nc17_20261026.zip` в `manifests/` и четыре инициализации
stage1 в `weights/`. Состав входов и форматы — в [stage2/README.md](stage2/README.md#данные).

```bash
python -m stage2.pipeline --gpus 0 1 2 --out work/nc17_pipeline
```

Скрипт проверяет входы, обучает две тройки учителей, получает мягкие NB-цели
и stage2-логиты, обучает студента до epoch=32 по расписанию 40 эпох,
обучает калибратор и считает NB-метрики. Готовый комплект —
`work/nc17_pipeline/final/{model.pt,policy.pkl,encoder_transform.pkl,calibration.json}`.
Для одной карты укажите `--gpus 0`; для продолжения — ту же команду с `--resume`.
`--dry-run` печатает план, `--check-only` проверяет входы без запуска обучения.

## Вычислительный бюджет и материалы

Модель с pooling — **93.116 GFLOPs**. На A100 + Xeon 8358 при `--batch-size 1`
и CUDA Graph: среднее **35.94 мс**, p95 **47.07 мс**, включая чтение JPEG
и калибровку, без записи PNG. Возможны небольшие отличия округления от batch 4;
H100 ещё не измерен.
